# 모동노트 계정 삭제 안내

모동노트 계정과 앱 데이터를 삭제하려면 앱 안의 회원 탈퇴 기능을 이용해 주세요.

## 앱 안에서 삭제하는 방법

```text
내 정보 > 계정 관리 > 회원 탈퇴
```

회원 탈퇴를 완료하면 모동노트 계정과 관련 앱 데이터가 삭제됩니다.

## 삭제되는 데이터

회원 탈퇴 시 현재 삭제 대상에 포함되는 데이터는 다음과 같습니다.

- Supabase Auth 사용자 계정
- 위시리스트
- 무 가격 기록
- 방문자 기록
- 커뮤니티 게시글
- 프로필/섬 정보
- 우리 섬 주민
- 기증 기록
- 운영/특수 계정 정보

## 남을 수 있는 데이터

다음 데이터는 서비스 운영, 보안, 감사, 법적 의무 이행을 위해 개인 식별자를 제거하거나 분리한 형태로 남을 수 있습니다.

- 운영 감사 로그
- 앱 업데이트 공지 또는 광고 설정 변경 이력
- 이미 집계된 주민 랭킹/통계
- 외부 소셜 로그인 제공자에 남아 있는 연결 기록

카카오 로그인 사용자의 경우 앱은 카카오 연결 끊기를 함께 시도합니다. 카카오 연결 해제가 실패한 경우에도 모동노트 내부 데이터 삭제는 계속 진행될 수 있으며, 카카오 계정 설정에서 연결 상태를 별도로 확인할 수 있습니다.

## 앱에 로그인할 수 없는 경우

앱 안에서 회원 탈퇴를 진행할 수 없다면 아래 이메일로 삭제 요청을 보내 주세요.

```text
modongnote@gmail.com
```

요청 시 다음 정보를 함께 보내 주세요.

- 가입한 이메일 주소
- 사용한 로그인 방식: 이메일, Kakao, Google, Apple
- 삭제 요청 문구: `모동노트 계정 삭제를 요청합니다.`

계정 소유 확인이 필요한 경우 추가 확인 절차가 있을 수 있습니다.

## 처리 기간

앱 안에서 회원 탈퇴를 완료한 경우 삭제는 즉시 처리됩니다. 이메일로 요청한 경우 계정 확인 후 가능한 한 빠르게 처리하며, 추가 확인이 필요한 경우 답변이 지연될 수 있습니다.
