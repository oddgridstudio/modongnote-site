## 3. 로컬 저장소 사용

모동노트는 앱 반응성과 오프라인 복원을 위해 기기 안에 일부 데이터를 저장합니다.

- AsyncStorage: 세션, 프로필 캐시, 위시리스트 UI 상태, 기증 기록, 무 가격 기록, 방문자 기록, 일일 체크리스트, 앱 공지 닫기 이력, 광고 노출 제한 정보
- SQLite: 외부 API 캐시, 번역 캐시, 주민 통계 동기화 재시도 큐

기기 안에 저장된 정보는 앱 삭제, 로그아웃, 계정 전환, 회원 탈퇴 흐름에서 일부 또는 전체가 초기화될 수 있습니다.

## 4. 개인정보 이용 목적

모동노트는 다음 목적을 위해 개인정보를 이용합니다.

- 회원가입, 로그인, 세션 유지
- 주민님의 섬 정보와 앱 설정 저장
- 위시리스트, 기증 기록, 무 가격, 방문자 기록 동기화
- 계정 전환 시 다른 계정의 데이터가 보이지 않도록 로컬 캐시 소유자 확인
- 광장 게시글 작성, 표시, 삭제, 운영 조치
- 주민 랭킹과 통계 집계
- 앱 업데이트 공지 및 운영 공지 표시
- 광고 표시, 광고 빈도 제한, 심사/운영 계정 광고 제외
- 장애 대응, 보안, 부정 사용 방지

## 5. 제3자 서비스

모동노트는 앱 기능 제공을 위해 다음 외부 서비스를 사용합니다.

| 서비스 | 역할 | 처리될 수 있는 정보 |
| --- | --- | --- |
| Supabase | 인증, 데이터베이스, 스토리지, Edge Function | 계정 정보, 앱 저장 데이터, 세션 정보, 운영 설정 |
| Kakao | 카카오 소셜 로그인, 연결 해제 | 카카오 계정 식별자, 로그인 토큰 |
| Google | Google 소셜 로그인, Google Mobile Ads | Google 계정 로그인 정보, 광고 ID, 광고/진단/상호작용 정보 |
| Apple | Apple 로그인 | Apple 계정 식별자, 이름/이메일 또는 비공개 릴레이 이메일 |
| Nookipedia | 도감 데이터 API | API 요청 정보, 도감 데이터 응답 |

광고가 활성화된 경우 Google Mobile Ads SDK가 광고 제공, 측정, 부정 사용 방지를 위해 정보를 수집하거나 공유할 수 있습니다. 현재 앱 구현은 광고 요청 시 비맞춤형 광고 옵션을 사용합니다. 맞춤형 광고 또는 iOS App Tracking Transparency 동의 흐름을 도입하는 경우 이 방침과 스토어 제출 답변을 함께 갱신합니다.

## 7. 보유 및 삭제

회원 데이터는 계정 유지 기간 동안 보관합니다. 주민님이 회원 탈퇴를 요청하면 앱은 계정과 관련 앱 데이터를 삭제합니다.

현재 삭제 대상에 포함되는 데이터:

- Supabase Auth 사용자 계정
- 위시리스트
- 무 가격 기록
- 방문자 기록
- 커뮤니티 게시글
- 프로필/섬 정보
- 우리 섬 주민
- 기증 기록
- 운영/특수 계정 정보

운영 감사 로그, 공지, 광고 설정처럼 운영 기록과 연결된 일부 데이터는 사용자 ID를 제거하여 개인 식별성을 낮추거나 없앨 수 있습니다.

카카오 로그인 사용자의 경우 앱은 카카오 연결 끊기를 함께 시도합니다. 카카오 연결 해제가 실패한 경우에도 모동노트 내부 데이터 삭제는 계속 진행될 수 있으며, 주민님은 카카오 계정 설정에서 연결 상태를 별도로 확인할 수 있습니다.

## 8. 계정 삭제 방법

앱 안에서 다음 경로로 회원 탈퇴를 요청할 수 있습니다.

```text
내 정보 > 계정 관리 > 회원 탈퇴
```

웹 안내는 다음 페이지에서 확인할 수 있습니다.

```text
https://oddgridstudio.github.io/modongnote-site/account-deletion/
```
